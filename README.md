# StreamIT – OTT Management System

A Java-based OTT Management System developed to manage movies,
users, subscriptions, watchlists, reviews, and administrative operations.

## Features

- User registration and login
- Movie browsing and search
- Movie details and reviews
- Watchlist management
- Subscription management
- Admin dashboard
- Movie management
- User management
- Revenue and statistics
- File-based data management

## Technologies Used

- Java
- Java Swing
- Object-Oriented Programming
- File Handling
- Git & GitHub
